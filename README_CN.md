# Sortiva

> **Sortiva** — 基于遗传算法的均衡分组解决方案 — [快速开始](#section1) 



## 简介
Sortiva 是一款面向教育场景的智能分组工具
通过以**学生成绩 、性别**等作为依据进行均衡分组
系统会运用多种算法，在多维度约束下寻找最优分组方案

### 功能特性

- **智能识别** — 自动识别,拆分 Excel 表格中的数据
- **多维均衡** — 成绩均分、性别比例、科目多样性同时优化
- **关系约束** — 支持"必须同组"、"不能同组"等约束
- **数据仪表盘** — 班级洞察、组间对比、班级情况分析等
- **一键导出** — 支持导出分组结果、分析报告

## 快速开始

#### 在线使用
>⚠️注意:该链接为静态页面,不涉及数据上传服务器等操作
- [点我进入](https://gavineg.github.io/Sortiva)

#### 本地部署
1. 拉取仓库
```bash
python -m http.server [port]（请修改为本机任意空闲端口）
```
2. 在仓库所在文件夹内运行终端，键入命令
```bash
python -m http.server [port]（请修改为本机任意空闲端口）
```
3. 打开浏览器，进入
```
localhost:[port]/index.html
```
4. 上传包含学生**成绩(不含总分),性别**的 Excel 文件[样例文件](./Example_Score_Excel_CN.xlsx)
5. 选择分组模式和参数
6. 点击"开始分组"
7. 查看结果，拖拽微调，导出报告
